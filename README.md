# Markdown Editor Advanced

A more capable sibling of [Markdown Editor](https://github.com/baldrin/markdown-editor). It starts from the same single-file editor and adds features that the original deliberately leaves out.

The original stays small, offline, and dependency-free. This one is allowed to grow.

**Try it live:** https://baldrin.github.io/markdown-editor-advanced/

## Features so far

- Markdown syntax highlighting in the editor pane
- Find and replace (`⌘F`, with match case and regular expression options)

## Planned

- Print to PDF
- Multiple documents, stored in the browser
- Image paste
- Installable as an app (PWA) with offline support
- Math rendering, loaded on demand

## Usage

Use the [hosted version](https://baldrin.github.io/markdown-editor-advanced/), or open `index.html` in any modern browser.
